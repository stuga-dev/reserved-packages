# stuga-mcp

Stuga's MCP server is not installed from npm. It runs on your Stuga node.

Connect your MCP client to `<your node's address>/mcp`, or open **Settings → Your own AI** in Stuga
for a setup made for your node. See [Agents and MCP](https://github.com/stuga-dev/stuga/blob/main/docs/agents.md).

This package name is reserved for the [Stuga](https://github.com/stuga-dev/stuga) project. Running it
prints the lines above and exits with status 1. Its source is in
[stuga-dev/reserved-packages](https://github.com/stuga-dev/reserved-packages).
